# CurveDot 仕様書

実測図などの画像上で、曲線の長さ（円周）・角度・円の大きさを測るための計測ソフト。
RingDot（環状資料の面積・縦横計測）と同じ方式の、単一HTMLファイルで動作するブラウザ用ツールである。

- バージョン： v1.0（2026-11-25）
- ファイル： `curvedot.html`（このファイル1つで動作する）

## 動作環境・前提

- モダンブラウザ（Chrome等）で `curvedot.html` を開くだけで動作する。サーバー不要、オフライン可。
- 画像データや計測結果が外部に送信されることはない（すべての処理はブラウザ内で完結する）。
- 計測は、画像上の点をクリックして指定する手動方式である。自動の輪郭抽出は行わない。
- 実寸（mm）での計測には、先に縮尺の校正が必要である。校正しない場合はピクセル単位で表示される。

## 機能

1. **画像の読み込み**：ファイル選択またはドラッグ＆ドロップ。マウスホイールで拡大縮小、ドラッグ（移動モード／スペース併用）で表示位置の移動。
2. **縮尺の校正**：スケールバーなど実寸が分かる2点をクリックし、実寸（mm）を入力する。以後の長さは mm で表示される。
3. **曲線の計測**：曲線に沿って点を打ち、折れ線として確定する。開いた曲線の長さのほか、閉じて確定すると周の長さ（円周）が得られる。各点での方向の変化を合計した「曲がり角度の合計」も表示する。
4. **角度の計測**：端→頂点→端の順に3点をクリックし、そのなす角を表示する。
5. **円の計測**：円周上の3点をクリックし、その3点を通る円の半径・直径・円周と、1点目から3点目までの弧の中心角を表示する。
6. **結果の管理**：計測結果は一覧に蓄積され、個別に削除できる。CSV形式で保存できる（Excelで開けるようBOM付きUTF-8）。

## 計測原理・計算方法

- **縮尺**：校正2点間のピクセル距離 ÷ 実寸（mm） を「1mmあたりのピクセル数」とし、以後の長さは ピクセル距離 ÷ この値 で mm に換算する。
- **曲線の長さ**：点列を結ぶ折れ線の長さの合計。閉曲線では最終点から始点へ戻る区間も加算する。折れ線による近似のため、点を細かく打つほど実際の曲線の長さに近づく。
- **曲がり角度の合計**：隣り合う3点ごとに、進む方向の変化量（−180°〜+180°）を求め、その絶対値の合計。
- **角度**：頂点Bに対し、2辺BA・BCの内積から求めるなす角（0°〜180°）。
- **円**：3点の外接円。中心は3点の垂直二等分線の交点（外心）、半径は中心から各点までの距離。円周は 2πr。弧の角度は、中心から見た1点目と3点目のなす角。

## 精度と限界

- 精度は、元の画像の解像度と、クリック位置の正確さに依存する。
- 曲線の長さは折れ線近似であり、点の間隔が粗いと実際より短く出る。
- 角度・円の計測は、指定した3点のみに依存する。円に近い弧では、3点をなるべく離して取る方が安定する。
- 縮尺の校正は画像全体に一様とみなす。スキャンの歪みなど、場所による縮尺の差は補正しない。

## 使い方

1. 「画像を開く」から実測図の画像を選ぶ。
2. 「縮尺」モードでスケールバーの両端をクリックし、実寸（mm）を入力する（例：10cmのバーなら100）。
3. 「曲線」「角度」「円」の各モードで計測する。曲線は点を打ち終えたら「曲線を確定」または「閉じて確定（円周）」を押す。
4. 結果は右側の一覧に溜まる。必要に応じて「CSVで保存」する。
